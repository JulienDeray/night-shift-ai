<objective>
Update handoff file naming to include a task-ID suffix so concurrent runs targeting the same agent cannot overwrite each other's handoff files. Introduce per-agent subdirectories under the existing handoff tmpdir.

Purpose: When `maxConcurrent > 1`, multiple runs for the same agent could collide on bare filenames like `analysis.json`. The new pattern `{handoffDir}/code-agent/handoff-code-agent-{taskId}.json` (one file per run, all bead data packed under structured keys) eliminates this risk per the locked CONTEXT.md decision. This is the foundation for the per-agent handoff model used in Phases 6+.

Output: Single handoff file per run (`handoff-code-agent-{taskId}.json`) with per-bead keys, per-agent subdirectory created, all bead reads/writes updated, pipeline behavior identical.
</objective>
