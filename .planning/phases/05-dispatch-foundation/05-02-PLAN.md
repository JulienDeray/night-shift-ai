<objective>
Update handoff file naming to include a task-ID suffix so concurrent runs targeting the same agent cannot overwrite each other's handoff files. Introduce per-agent subdirectories under the existing handoff tmpdir.

Purpose: When `maxConcurrent > 1`, multiple runs for the same agent could collide on bare filenames like `analysis.json`. The new pattern `{handoffDir}/code-agent/handoff-code-agent-{taskId}-{beadName}.json` eliminates this risk. This is the foundation for the per-agent handoff model used in Phases 6+.

Output: Handoff filenames include taskId suffix, per-agent subdirectory created, all bead reads/writes updated, pipeline behavior identical.
</objective>
