## Decisions Made
- Single handoff file per run with structured keys rather than one file per bead — this is the CONTEXT.md locked decision. Keys: `analysis` (written by analyze bead after parsing), `verify` (merged by verify bead).
- The `handoffPath()` helper is module-private to `code-agent-runner.ts` — it uses `PipelineContext` fields directly, keeping all filename logic in one place.
- `runVerifyBead` pre-reads the existing file (catching the `analysis` key from analyze bead) before writing the stub — this prevents the structured verify stub from clobbering analysis data, ensuring the MR bead can still read analysis.
