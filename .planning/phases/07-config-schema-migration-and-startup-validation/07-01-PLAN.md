<objective>
Rewrite the nightshift.yaml Zod schema from the hardcoded `code_agent:` + `recurring:` model to the new `agents:` + `schedule:` model, update all TypeScript types, and remove dead references from the daemon/CLI modules.

Purpose: The current config schema is tightly coupled to the code-agent. The new `agents:` array + `schedule:` array model is the foundation for running any number of manifest-based agents on independent cron schedules. This is MIGR-02.

Output: Rewritten config.ts, types.ts, updated orchestrator/agent-pool/scheduler/CLI commands, and fully rewritten config.test.ts.
</objective>

  <action>
**types.ts changes:**

1. Remove these interfaces entirely: `CategoryScheduleConfig`, `CodeAgentConfig`, `RecurringTaskConfig`
2. Add new interfaces:

```typescript
export interface AgentDeclaration {
  name: string;
  notify?: boolean;
  variables?: Record<string, string>;
}

export interface ScheduleEntry {
  agent: string;
  cron: string;
  variables?: Record<string, string>;
  enabled: boolean;
  notify?: boolean;
}
```

3. Update `NightShiftConfig`:
   - Remove `recurring: RecurringTaskConfig[]` and `codeAgent?: CodeAgentConfig`
   - Add `agentsDir: string` (default "./agents")
   - Add `agents: AgentDeclaration[]`
   - Add `schedule: ScheduleEntry[]`
   - Keep all other fields: workspace, inbox, maxConcurrent, defaultTimeout, beads, daemon, oneOffDefaults, ntfy

**config.ts changes:**

1. Remove `CategoryScheduleSchema`, `CodeAgentSchema`, `RecurringTaskSchema` entirely
2. Add `AgentDeclarationSchema`:
   - `name`: `z.string().regex(/^[a-z][a-z0-9-]*$/, "must be kebab-case")`
   - `notify`: `z.boolean().optional()`
   - `variables`: `z.record(z.string(), z.string()).optional()`
   - Use `.strict()`

3. Add `ScheduleEntrySchema`:
   - `agent`: `z.string().min(1)`
   - `cron`: `z.string().min(1)`
   - `variables`: `z.record(z.string(), z.string()).optional()`
   - `enabled`: `z.boolean().default(true)`
   - `notify`: `z.boolean().optional()`
   - Use `.strict()`

4. Rewrite `ConfigSchema`:
   - Keep: `workspace`, `inbox`, `max_concurrent`, `default_timeout`, `beads`, `daemon`, `one_off_defaults`, `ntfy`
   - Add: `agents_dir: z.string().default("./agents")`
   - Add: `agents: z.array(AgentDeclarationSchema).default(() => ([]))`
   - Add: `schedule: z.array(ScheduleEntrySchema).default(() => ([]))`
   - Remove: `recurring`, `code_agent`
   - CRITICAL: Add `.strict()` to ConfigSchema (rejects unknown keys like `code_agent:`, `recurring:`)
   - Add `.superRefine()` on the root schema for three cross-validations:
     a. **Duplicate agent names**: Check agents array for duplicate `name` values. Error: `Duplicate agent name: 'foo'`
     b. **Schedule references**: Every `schedule[i].agent` must exist in `agents[j].name`. Error: `Schedule references unknown agent 'foo'`
     c. **Cron validation**: For each enabled schedule entry, validate the cron expression by instantiating `new Cron(entry.cron)` in a try/catch. Error: `Invalid cron expression: '...'`
   - Import `Cron` from "croner" at the top of config.ts

5. Rewrite `mapConfig()`:
   - Remove `recurring` and `codeAgent` mapping
   - Add `agentsDir: raw.agents_dir`
   - Add `agents: raw.agents.map(a => ({ name: a.name, notify: a.notify, variables: a.variables }))`
   - Add `schedule: raw.schedule.map(s => ({ agent: s.agent, cron: s.cron, variables: s.variables, enabled: s.enabled, notify: s.notify }))`

6. Rewrite `getDefaultConfigYaml()`:
   - Remove `recurring: []` and all `# recurring` and `# code_agent:` examples
   - Add `agents_dir: ./agents`
   - Add `agents: []` with commented example:
     ```
     # agents:
     #   - name: code-agent
     #     variables:
     #       repo_url: "git@gitlab.com:team/repo.git"
     ```
   - Add `schedule: []` with commented example:
     ```
     # schedule:
     #   - agent: code-agent
     #     cron: "0 2 * * 1-5"
     #     variables:
     #       category: "refactoring"
     #   - agent: code-agent
     #     cron: "0 2 * * 6"
     #     variables:
     #       category: "tests"
     ```
   - Keep `one_off_defaults` and `ntfy` sections as-is
