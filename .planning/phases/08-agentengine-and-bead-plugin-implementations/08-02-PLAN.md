**`run<T>()` method:**

Signature: `async run<T = unknown>(agentDir: string, agentsRoot: string, taskId: string, configOverrides?: Record<string, string>): Promise<AgentRunResult<T>>`

Implementation flow (follow the order strictly):

1. **Generate run ID:** `crypto.randomUUID()` (Claude discretion item -- use UUID).
2. **Record start time:** `Date.now()`.
3. **Create temp dir:** `const tmpDirManager = new TempDirManager(this.logger); const { tmpDir, repoDir, handoffDir } = await tmpDirManager.create(runId);`
4. **Load manifest:** `const manifest = await loadManifest(agentDir, agentsRoot);` -- if this throws, cleanup tmpDir and return a FATAL result. Do NOT rethrow.
5. **Build initial variables:**
   - `const builtIns = buildBuiltIns(taskId, manifest.name, repoDir);`
   - `const initialVars = buildTemplateVars(builtIns, manifest.variables, configOverrides ?? {}, {});`
6. **Build initial context:**
   ```typescript
   let ctx: AgentPipelineContext = {
     taskId, agentName: manifest.name, agentDir: manifest.agentDir,
     workDir: repoDir, handoffDir,
     manifest, currentBead: manifest.beads[0],
     previousBeads: {}, variables: initialVars,
   };
   ```
7. **Bead loop:** `for (let i = 0; i < manifest.beads.length; i++)`
   - Update `ctx.currentBead = manifest.beads[i]`.
   - Record `beadStart = Date.now()`.
   - **Log bead start:** `this.logger.info("Bead started", { runId, bead: bead.name, type: bead.type, index: i })`.
   - **Resolve plugin:** `const factory = this.registry.resolve(bead.type); const plugin = factory(bead, manifest);`
   - **Execute:** `const output = await plugin.execute(ctx);` wrapped in try/catch.
   - **On error:**
     - Compute `durationMs`.
     - Categorize error via `categorizeError(err, /* check if timeout */)`.
     - Push `{ name: bead.name, status: "FAILED", durationMs, error: String(err) }` to `perBead`.
     - Mark remaining beads as SKIPPED (push `{ name, status: "SKIPPED", durationMs: 0 }` for each).
     - **Log bead failure:** `this.logger.error("Bead failed", { runId, bead: bead.name, error: String(err).slice(0, 500), category })`.
     - **Cleanup (rollback):** `await tmpDirManager.cleanup(tmpDir);`
     - **Log run summary:** structured summary object with all perBead statuses.
     - Return `AgentRunResult` with `status: category, failedBeadIndex: i, errorCategory: category, error: String(err)`. Set `suggestedDelayMs: category === "TRANSIENT" ? 60_000 : undefined`.
   - **On success:**
     - Compute `durationMs`.
     - **Validate bead output:** `const parsed = validateBeadOutput(output.rawOutput, bead.compiledOutputSchema, bead.name);` -- if this throws (BeadContractViolationError or BeadOutputMissingError), treat it the same as a bead execution failure (go to error handling above).
     - **Accumulate context:** Update `ctx.previousBeads` with `{ [bead.name]: { output: parsed, rawOutput: output.rawOutput } }`.
     - **Rebuild variables:** `ctx.variables = buildTemplateVars(builtIns, manifest.variables, configOverrides ?? {}, ctx.previousBeads);` -- this makes `{{beads.analyze.output.field}}` available to later beads.
     - Push `{ name: bead.name, status: "SUCCESS", durationMs }` to `perBead`.
     - **Log bead success:** `this.logger.info("Bead completed", { runId, bead: bead.name, durationMs, inputPreview: "...", outputPreview: output.rawOutput.slice(0, 200) })`.

8. **After loop (all beads succeeded):**
   - **Cleanup:** `await tmpDirManager.cleanup(tmpDir);`
   - Compute `totalDurationMs`.
   - Extract final output: `ctx.previousBeads[manifest.beads.at(-1)!.name]?.output ?? null` cast as `T`.
   - **Log run summary:** structured completion log.
   - Return `AgentRunResult` with `status: "SUCCESS"`.

**`dryRun()` method:**

Signature: `async dryRun(agentDir: string, agentsRoot: string, configOverrides?: Record<string, string>): Promise<void>`

Per locked CONTEXT.md decision, dry-run checks without creating temp dirs or executing beads:

1. **Load manifest:** `await loadManifest(agentDir, agentsRoot);` -- validates schema, env vars, path containment.
2. **Check plugins registered:** For each bead in manifest, call `this.registry.resolve(bead.type)` -- throws RegistryError if missing.
3. **Check prompt files exist:** For each bead, `await fs.access(path.join(manifest.agentDir, bead.prompt))` -- throws if missing.
4. **Validate template variables:** Build built-in placeholders as `{ task_id: "<task_id>", run_date: "<run_date>", agent_name: "<agent_name>", repo_path: "<repo_path>" }` (placeholder strings, same pattern as startup-validation from Phase 7). Then `buildTemplateVars(placeholders, manifest.variables, configOverrides ?? {}, {})`. For each bead with a prompt, read the prompt file and call `validateTemplateVars(promptContent, vars)`.

**`categorizeError()` private function (module-level):**

Per locked CONTEXT.md:
- Timeouts: FATAL (check if error message contains "timed out" or error is a timeout indicator).
- `BeadOutputMissingError`: TRANSIENT (Claude produced no JSON -- might succeed on retry).
- `BeadContractViolationError`: TRANSIENT (output didn't match schema -- might produce valid output on retry).
- `ManifestSecurityError`: FATAL (path traversal -- structural problem).
- `ManifestError`: FATAL (bad manifest -- structural problem).
- `RegistryError`: FATAL (unknown bead type -- structural problem).
- Default for unknown errors: FATAL (safe default).

Accept a `timedOut: boolean` parameter. If `timedOut` is true, return FATAL immediately.

**Anti-patterns to avoid (per locked decisions):**
- NO references to "code-agent", category rotation, or any agent-specific constant. `grep -r "code-agent" src/agent/engine.ts` must return zero.
- NO EventEmitter or mid-execution events -- logs only.
- NO global pipeline timeout -- only per-bead timeouts from manifest.
- NO retry logic in engine -- return categorized error, caller decides.
- Rollback failures logged as warn, original error always returned.
- `dryRun()` must NOT create any temp dirs or runId.
