**2. Create `src/agent/plugins/standard-bead-plugin.ts`:**

```typescript
import fs from "node:fs/promises";
import path from "node:path";
import { runBead } from "../bead-runner.js";
import { renderAgentTemplate } from "../template.js";
import { parseTimeout } from "../../utils/process.js";
import type { BeadPlugin, AgentPipelineContext, BeadOutput } from "../bead-plugin.js";
```

- Implements `BeadPlugin` interface.
- `execute(ctx)`:
  1. Read prompt file: `await fs.readFile(path.join(ctx.agentDir, ctx.currentBead.prompt), "utf-8")`
  2. Render template: `renderAgentTemplate(rawPrompt, ctx.variables)`
  3. Parse timeout: `parseTimeout(ctx.currentBead.timeout)`
  4. Resolve gitlabToken: check if `ctx.currentBead.env` includes an entry with `name === "GITLAB_TOKEN"` -- if so, use its `value`; otherwise `undefined`.
  5. Build env vars object from `ctx.currentBead.env`: `Object.fromEntries(ctx.currentBead.env.map(e => [e.name, e.value]))` -- but do NOT pass this to runBead directly. The `runBead` function uses `buildBeadEnv` internally. The plugin only passes `gitlabToken` and `allowedTools` through the options.
  6. Call `runBead({ beadName: ctx.currentBead.name, prompt: renderedPrompt, model: ctx.currentBead.model, cwd: ctx.workDir, timeoutMs, gitlabToken, allowedTools: ctx.currentBead.allowedTools })`.
  7. Check result: if `result.exitCode !== 0 && !result.timedOut`, throw an Error with stderr info. If `result.timedOut`, throw an Error indicating timeout (the engine's `categorizeError` will mark it FATAL).
  8. Return `{ rawOutput: result.stdout }`.

**IMPORTANT**: Do NOT call `validateBeadOutput()` from the plugin. The engine (Plan 02) handles output validation after the plugin returns. The plugin is a thin wrapper -- it delegates to `runBead()` and returns raw output.

**3. Create `src/agent/plugins/git-clone-bead-plugin.ts`:**

```typescript
import { cloneRepo } from "../git-harness.js";
import type { BeadPlugin, AgentPipelineContext, BeadOutput } from "../bead-plugin.js";
```

- Implements `BeadPlugin` interface.
- `execute(ctx)`:
  1. Extract `repo_url` from `ctx.variables["repo_url"]`. Throw if missing: `"GitCloneBeadPlugin requires 'repo_url' variable"`.
  2. Extract `gitlabToken` from `ctx.currentBead.env` (same pattern as StandardBeadPlugin).
  3. Determine `repoDir`: use `ctx.workDir` (the engine pre-creates this as `{runTmpDir}/repo/`).
  4. Call `cloneRepo(repoUrl, gitlabToken, repoDir)`.
  5. Return `{ rawOutput: JSON.stringify({ repoDir: cloneResult.repoDir, handoffDir: cloneResult.handoffDir }) }`.
  - Note: The engine will parse this output and update `ctx.workDir` accordingly. The plugin itself just wraps `cloneRepo()`.
