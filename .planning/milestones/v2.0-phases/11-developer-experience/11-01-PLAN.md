  <name>Task 2: Create agent CLI subcommand group with init, validate, list, show</name>
  <files>src/cli/commands/agent.ts, src/cli/index.ts</files>
  <action>
Create `src/cli/commands/agent.ts` following the exact pattern of `config.ts` (Commander subcommand group).

**Subcommand group setup:**
```typescript
import { Command } from "@commander-js/extra-typings";
export const agentCommand = new Command("agent").description("Manage agents");
```

**1. `agent init` subcommand:**
- `.command("init").argument("<name>", "Agent name (kebab-case)").option("--force", "Overwrite existing agent directory")`
- Action: call `scaffoldAgent(name, { force: options.force })` from `../agent/scaffold.js`
- On success: print `success("Agent '<name>' created at agents/<name>/")`. If `configUpdated`, print `info("Added to nightshift.yaml with schedule: 0 2 * * *")`. Print the next-steps message from the result.
- On error: print `error(err.message)`, set `process.exitCode = 1`.

**2. `agent validate` subcommand:**
- `.command("validate").argument("<path>", "Agent name or directory path")`
- Path resolution: if arg contains no path separators (`/` or `\`), resolve as `path.resolve(base, config.agentsDir ?? 'agents', arg)`. Otherwise resolve relative to cwd.
- Validation checks (in order, collect all results before printing):
  a. **Schema validation:** Call `loadManifest(agentDir, agentsRoot)` inside try/catch. If it throws `ManifestError` with message containing "env var" and "is not set", downgrade to warning (not error). All other `ManifestError` throws are errors. `ManifestSecurityError` is an error.
  b. **Prompt file existence:** For each bead in manifest, check `fs.access(path.join(agentDir, bead.prompt))`. Also check preamble if `preamble.md` exists pattern.
  c. **Variable completeness:** For each bead prompt file, read content, call `validateTemplateVars(content, vars)` where vars includes manifest variables + built-in placeholder strings. Catch `ManifestError` as error.
  d. **Output schema compilation:** Already done inside `loadManifest` — if it passed schema check, outputSchema compiled.
  e. **Env var availability:** For each bead's `env` entries (string passthrough type), check `process.env[name]`. Missing = warning.
- Output: Print each check with checkmark (success) or X (error) or warning triangle (warn). Example: `success("Schema: valid")`, `success("Prompts: all files present")`, `warn("Env: GITLAB_TOKEN not set in current environment")`.
- Exit: if any errors, `process.exitCode = 1`.

  Implementation note: since `loadManifest` resolves env vars and throws on missing ones, use a two-pass approach:
  - First, parse manifest YAML directly with `parseYaml` + `ManifestSchema.safeParse()` for schema validation without env resolution.
  - Then attempt `loadManifest()` to test env vars — catch `ManifestError` containing "env var" as warning.
  - Read prompt files from the parsed manifest beads for variable completeness checks.

**3. `agent list` subcommand (also aliased as `agents list` per CONTEXT.md namespace):**
- `.command("list").option("--json", "Output as JSON")`
- Load config via `loadConfig()` (catch `ConfigError` — fall back to no schedule info).
- Scan `agents/` directory for subdirectories containing `manifest.yaml`.
- For each discovered agent: parse `manifest.yaml` with `parseYaml` (do NOT use `loadManifest` — it throws on missing env vars). Extract name and bead count.
- Read JSONL run log from `path.join(getLogsDir(base), "agent-runs.jsonl")`. Parse lines, find last entry per agent by `agent_name`.
- Build rows with 4 columns: Name, Beads (count), Schedule (cron from config or "(not scheduled)"), Last Run (summary + relative time from `date-fns` `formatDistanceToNow`, or "never").
- If `--json` flag: output JSON array of `{ name, beads, schedule, lastRun }`.
- If no agents found: print `info("No agents found. Run 'nightshift agent init <name>' to create one.")`.
- Use `table()` from `formatters.ts` for table rendering.

**4. `agent show` subcommand:**
- `.command("show").argument("<name>", "Agent name")`
- Resolve agent directory: `path.resolve(base, config?.agentsDir ?? 'agents', name)`.
- Parse manifest via `parseYaml` (not `loadManifest` — avoid env var errors).
- Print sections using `heading()` formatter:
  a. **Manifest Summary:** name, description, model, timeout, variable count, variable names
  b. **Bead Pipeline:** Numbered list of beads with type, model override (if different from agent default), retry config (if present), prompt file path
  c. **Schedule:** If in nightshift.yaml, show cron expression + next run time via `new Cron(cron).nextRun()` from `croner`. Otherwise "(not scheduled)".
  d. **Recent Runs:** Last 5 entries from JSONL log filtered by agent name. Show timestamp, summary, duration via `formatDuration()`. If no runs: "No runs recorded yet."
