<objective>
Wire AgentPool.dispatch() to use AgentEngine instead of AgentRunner, adopt AgentRunResult natively across the daemon (orchestrator, reporter, run-logger), and implement category fallback dispatch in the orchestrator.

Purpose: This is the core wiring that makes the daemon run agents through the new manifest-driven engine. After this plan, every task dispatch goes through AgentEngine's bead pipeline — the old AgentRunner path is dead code (deleted in Plan 02).

Output: AgentPool dispatches via AgentEngine, orchestrator handles AgentRunResult with per-bead data, JSONL logging is agent-agnostic, and fallback categories work as separate re-dispatched tasks.
</objective>
