**Function signature:**
```typescript
export async function validateAgentsAtStartup(
  config: NightShiftConfig,
  configDir: string,
): Promise<void>
```

**Implementation:**

1. **Early return if no agents:** `if (config.agents.length === 0) return;`

2. **Resolve agents root directory:** `const agentsRoot = path.resolve(configDir, config.agentsDir);`

3. **Collect all schedule-level variable overrides per agent:**
   Build a `Map<string, Record<string, string>[]>` mapping agent name to an array of variable override objects from schedule entries:
   ```typescript
   const scheduleVarsByAgent = new Map<string, Record<string, string>[]>();
   for (const entry of config.schedule) {
     if (!scheduleVarsByAgent.has(entry.agent)) {
       scheduleVarsByAgent.set(entry.agent, []);
     }
     if (entry.variables) {
       scheduleVarsByAgent.get(entry.agent)!.push(entry.variables);
     }
   }
   ```

4. **Iterate all declared agents, collecting errors:**
   ```typescript
   const errors: string[] = [];
   for (const agent of config.agents) {
     const agentDir = path.join(agentsRoot, agent.name);
     try {
       // Step A: Load and validate manifest (Phase 6 loadManifest handles
       //         path containment, Zod validation, env var resolution)
       const manifest = await loadManifest(agentDir, agentsRoot);

       // Step B: For each bead, validate prompt file exists and template vars resolve
       for (const bead of manifest.beads) {
         const promptPath = path.join(manifest.agentDir, bead.prompt);
         let promptContent: string;
         try {
           promptContent = await fs.readFile(promptPath, "utf-8");
         } catch {
           errors.push(`Agent '${agent.name}', bead '${bead.name}': prompt file not found: ${promptPath}`);
           continue; // Skip template validation for missing prompt
         }

         // Build the full variable map for template validation:
         // Built-in placeholders + manifest vars + agent-level config overrides + all schedule-level overrides
         const builtInPlaceholders: Record<string, string> = Object.fromEntries(
           BUILT_IN_VARS.map((v) => [v, `<${v}>`])
         );
         const allKnownVars: Record<string, unknown> = {
           ...manifest.variables,
           ...(agent.variables ?? {}),
           ...builtInPlaceholders,
         };
         // Merge all schedule-level overrides for this agent
         const scheduleOverrides = scheduleVarsByAgent.get(agent.name) ?? [];
         for (const overrides of scheduleOverrides) {
           Object.assign(allKnownVars, overrides);
         }

         try {
           validateTemplateVars(promptContent, allKnownVars);
         } catch (err) {
           errors.push(`Agent '${agent.name}', bead '${bead.name}': ${err instanceof Error ? err.message : String(err)}`);
         }
       }
     } catch (err) {
       // loadManifest can throw ManifestError, ManifestSecurityError, etc.
       errors.push(`Agent '${agent.name}': ${err instanceof Error ? err.message : String(err)}`);
     }
   }
   ```

5. **Throw if any errors collected:**
   ```typescript
   if (errors.length > 0) {
     const msg = `Startup validation failed — ${errors.length} error(s) across agent(s):\n\n` +
       errors.map((e, i) => `  [${i + 1}] ${e}`).join("\n\n");
     throw new ConfigError(msg);
   }
   ```

3. **"fails when agent directory does not exist"** — Mock `loadManifest` to throw `ManifestError("Cannot read manifest...")`. Should throw `ConfigError` containing the agent name.

4. **"fails when manifest has invalid schema"** — Mock `loadManifest` to throw `ManifestError("Manifest validation failed...")`. Should throw `ConfigError` containing the agent name and the original error.

5. **"fails when prompt file is missing"** — Mock `loadManifest` to return a manifest with a bead pointing to a non-existent prompt file. Should throw `ConfigError` containing "prompt file not found" and the bead name.

6. **"fails when template variable is undefined"** — Mock `loadManifest` to return a manifest with one bead. Create a prompt file containing `{{custom_var}}`. 7. **"passes when template variable is provided in manifest defaults"** — Same setup but `loadManifest` returns `variables: { custom_var: "value" }`. Should resolve.

8. **"passes when template variable is provided in agent-level config overrides"** — Mock `loadManifest` returns manifest without the variable. Config has `agents: [{ name: "test", variables: { custom_var: "value" } }]`. Should resolve.

9. **"passes when template variable is provided in schedule-level overrides"** — Mock `loadManifest` returns manifest without the variable. Config has a schedule entry with `variables: { custom_var: "value" }`. Should resolve.

10. **"built-in variables are recognized"** — Create prompt file with `{{task_id}}` and `{{run_date}}`. Should resolve (built-ins injected as placeholders).

11. **"beads.* variables are skipped at startup"** — Create prompt file with `{{beads.analyze.output.result}}`. Should resolve (beads.* skipped by validateTemplateVars).

12. **"collects errors from multiple agents"** — Config with two agents, both with broken manifests. Should throw `ConfigError` containing BOTH agent names and error count "2 error(s)".

13. **"collects errors from multiple beads in same agent"** — Mock `loadManifest` returns manifest with two beads, both pointing to missing prompt files. Should throw with errors mentioning both bead names.

14. **"env var check is delegated to loadManifest"** — This is already handled by `loadManifest`'s `resolveEnvVars`. Mock `loadManifest` to throw when env var is missing. Should propagate as a collected error.
